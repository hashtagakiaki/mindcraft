素手・防具なしで単独と複数の近接敵を比較し、複数体で死亡した原因に対応する戦闘処理を実装した。すべてローカルの隔離vanilla 1.21.1 / Normal、自然回復なし、平坦な41×41の囲いで実施した。元template・手動worldは変更せず、LLMは起動していない。各条件は少数の診断試行であり、勝率や全地形への保証ではない。

洞窟グモではHP10→3まで消耗したため、毒を持つ敵を通常の自動反撃対象には含めていない。

## 複数対象の戦闘処理

- 50msごとに近い脅威を選び直し、1体が死ぬまで他の敵を無視しない。対象切替は既存PVPの武器別攻撃間隔を守る。
- 近接時は全ての敵から距離を取るPathfinderの合成目標を使い、距離が開いたら追撃する。対象切替でPVPが上書きする追従目標も毎回戦闘側で置き換える。
- 新規対象の索敵radiusと、交戦済み対象の追跡範囲を分ける。退避・吹き飛ばしで8ブロックを出ただけでは戦闘を終了しない。死亡未確認のまま追跡範囲を失えば非成功とする。
- 死亡後1.5秒の追加観測で分裂した敵も扱う。自分の死亡・切断・取消では中止し、専用listenerと移動目標を解除する。
- 掘削や足場の許可、足場後の武器復元は既存の経路処理が担当する。

## 自動反撃の範囲

`cowardice` と `self_defense` が両方ONなら、HP10以上で単独、HP20なら最大3体の、手にアイテムを持たない地上のゾンビ（子供含む）・ハスク・村人ゾンビ・ドラウンド・クモへ共通の条件で反撃する。空腹度は6超が必要。毒・遠隔・爆発、水中、より大きな群れは退避を維持する。SDKのdefendSelf自体には3体の上限を置かない。

武器持ち、装甲の強い敵、水中、狭所、毒・爆発・遠隔攻撃、全ての混在編成は今回の成功範囲として主張しない。
